01 / Archivos

Lectura y búsqueda
ls
Lista archivos y carpetas.
archivo
Sintaxis
ls [ruta]
Argumento
Ruta de una carpeta. Si se omite usa el almacenamiento externo.
Ejemplos
lsls /storage/emulated/0/Download
Respuesta
JSON con name, type y size.
cat
Lee un archivo de texto.
archivo
Sintaxis
cat <ruta>
Ejemplo
cat /storage/emulated/0/Download/notas.txt
Límite
500 KB.
Android sólo permitirá leer rutas accesibles para la aplicación.
pwd
Devuelve la ruta base de almacenamiento externo.
archivo
Sintaxis
pwd
Ejemplo salida
/storage/emulated/0
find
Busca archivos desde el almacenamiento externo.
archivo
Sintaxis
find <término>
Ejemplos
find facturafind .pdf
Respuesta
Array JSON generado por searchFiles().

03 / Red y SIM

Wi‑Fi y telefonía
wifi
Información de la conexión Wi‑Fi.
permisos
Sintaxis
wifi
Devuelve
SSID, IP, RSSI, velocidad y MAC visible para Android.
Android moderno puede ocultar SSID/MAC o exigir permisos de ubicación o Wi‑Fi cercanas.
siminfo
Información básica de la SIM y red móvil.
permisos
Sintaxis
siminfo
Devuelve
Operador, país, phone type, network type, estado y operador SIM.
Permiso
READ_PHONE_STATE para datos protegidos.
ussd
Envía un código USSD mediante TelephonyManager.
CALL_PHONE
Sintaxis
ussd <código>
Ejemplo
ussd *123#
Requisito
Android 8+ / API 26+.
Timeout
20 segundos.
El operador o fabricante puede no admitir respuestas USSD mediante esta API.

android

sensible

inbox

05 / Ejecución

Proceso de la aplicación
shell
Ejecuta un comando con Runtime.exec().
restringido
Sintaxis
shell <comando>
Ejemplos
shell idshell getprop ro.build.version.release
Salida
stdout y stderr; errores llevan [ERR].
No es una shell root. Se ejecuta con los permisos y sandbox del UID de tu aplicación.

06 / Transferencia

Archivo → servidor
download
Sube un archivo del teléfono al servidor.
transferencia
Sintaxis
download <ruta>
Ejemplo
download /storage/emulated/0/Download/reporte.pdf
Destino
POST {serverUrl}/api/upload
Formato
multipart/form-data — campo file.
Límite
10 MB.
Aunque se llama download, tu implementación realmente hace un upload. Renombrarlo a upload haría la consola más clara.

07 / Permisos

Referencia rápida
CALL_PHONE
Necesario para ussd.
READ_PHONE_STATE
Datos protegidos usados por siminfo.
READ_CONTACTS
Necesario para contacts.
READ_SMS
Necesario para sms; permiso especialmente restringido.
READ_CALL_LOG
Necesario para calls; permiso sensible.
INTERNET
Necesario para enviar archivos con download.
Wi‑Fi / ubicación
El SSID y otros datos pueden requerir permisos adicionales según la versión de Android.
Scoped Storage
ls, cat, find y download están sujetos a las restricciones modernas de almacenamiento.
